We design, build, and operate production software end to end: backend systems, frontend applications, infrastructure, billing, deployment, and the operational details that decide whether software survives contact with real users.

Our work is concentrated in three areas:

- **AI systems** — orchestration engines, agent control planes, integrations, tools, and safety boundaries.
- **Venue operations** — ticketing, cinema operations, POS workflows, and customer-facing sales surfaces for the Mexican market.
- **Developer infrastructure** — Java/Spring libraries, authentication, UI systems, SDKs, and internal platform tooling.

## Public Work

- [mortar](https://github.com/sequelcore/mortar) — Java-first, refactor-safe, SQL-transparent queries for Spring and PostgreSQL.
- [sequel-backend-demo](https://github.com/sequelcore/sequel-backend-demo) — Public Spring Boot demo for Sequel backend libraries, starting with Mortar.
- [kiln](https://github.com/sequelcore/kiln) — Domain-agnostic AI orchestration engine for channels, tools, LLM providers, RAG, and safety pipelines.
- [kiln-integrations](https://github.com/sequelcore/kiln-integrations) — Official integration adapters for Kiln, including Google Calendar, Stripe, and Google Sheets.

## Operating Principles

- Build with boring foundations and sharp boundaries.
- Prefer explicit contracts over hidden framework behavior.
- Test before calling a system done.
- Keep data ownership clear.
- Design for the people who will run the system after launch.
